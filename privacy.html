Privacy Policy Last updated: 2026 "Content Factory" is a personal, single-user automation tool operated by its developer. This policy explains what data it handles. Data We Access When authorized via TikTok Login Kit, this application receives an OAuth access token and refresh token scoped to the developer's own TikTok account. These tokens are used only to publish video content to that same account via the Content Posting API, and are stored locally and privately on the developer's own device. Data We Do Not Collect This application does not collect, view, or store data belonging to any other TikTok user. It does not run on a server accessible to the public and has no other users besides its developer. Data Sharing No data is sold, shared, or transferred to any third party.
